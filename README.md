# Подготовка к магистратуре

Интерактивный локальный трекер подготовки к поступлению в магистратуру.

Содержит:

- карточки тем и вопросов для подготовки;
- фильтрацию по вузам;
- отметки прогресса с сохранением в `localStorage`;
- экспорт прогресса;
- локальные PDF с программами вступительных испытаний.

## Запуск

Открыть `index.html` в браузере.
